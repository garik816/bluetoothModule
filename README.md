# Bluetooth Audio Transmitter — ESP32-S3 / FSA506 / KCX v1.7

Керований через сенсорний екран передавач музики з магнітоли на Bluetooth-навушники/колонки.

**Актуальна апаратна конфігурація:**
- **ESP32-S3-N16R8** — єдиний програмований мікроконтролер, керує FSA506, сенсором та KCX через UART.
- **FSA506 / Ampire 480×272** — 8-бітний паралельний LCD 8080, RGB565.
- **4-wire Resistive Touch** — опитування через ADC1, 5-точкова калібровка з NVS.
- **KCX_BT_EMITTER v1.7** — окремий готовий Bluetooth Classic **A2DP Source** модуль із аналоговим стереовходом. ESP32-S3 **не передає A2DP сам**, тільки керує KCX.

## Функції прошивки

- Виведення виявлених навушників/колонок (назва, MAC, до 24 пристроїв, по 4 на сторінку).
- Сенсорні кнопки **SCAN**, **CONNECT**, **DROP**, **MORE**; вибір рядка зі списку.
- Стани KCX: очікування, пошук, під'єднання/роз'єднання, помилки.
- Калібрування Touch: п'ять міток (верх-ліво, верх-право, низ-право, низ-ліво, центр); зберігається у NVS \`fsa_touch/cal_v1\`. Для повторного калібрування натисніть у верхньому правому кутку заголовка.
- Послідовний адаптер KCX на **115200 8N1**: парсинг \`MacAdd:0x...\`, \`Name:\`, \`OK+STATUS:...\`, \`OK+VERS\`; лог усіх відповідей ESP-IDF console.
- Підтримка збереження **одного** обраного MAC у пам'яті KCX для автоматичного сполучення.

**Увага щодо KCX v1.7:** на деяких модулях \`AT+SCAN\` не працює. Прошивка використовує \`AT+PAIR\`, що активує пошук/сполучення і **може автоматично під'єднати** доступний пристрій. Для цільового вибору за MAC після натискання CONNECT відправляються \`AT+DISCON\`, \`AT+DELVMLINK\`, \`AT+ADDLINKADD=<MAC>\`, \`AT+PAIR\` із перевіркою підтверджень на етапах очистки та запису MAC. **Це стирає всі попередні улюблені Bluetooth-пристрої в пам'яті KCX.** Поведінка потребує перевірки з реальною ревізією плати/прошивки.

## Підключення ESP32-S3 / FSA506

Ця таблиця перенесена з робочої гілки [Silvus Configurator hw/esp32s3-fsa506](https://github.com/garik816/silvus-configurator/tree/hw/esp32s3-fsa506).

| FSA506 / Touch | ESP32-S3 GPIO |
|---|---:|
| LCD DB0..DB7 | 14, 15, 16, 17, 18, 21, 38, 39 |
| RS / DC | 40 |
| /WR | 41 |
| /CS | 47 |
| /RD | 42, постійно HIGH |
| Touch X1 (FFC30) | 1 / ADC1 |
| Touch X2 (FFC31) | 2 / ADC1 |
| Touch Y1 (FFC32) | 7 / ADC1 |
| Touch Y2 (FFC33) | 8 / ADC1 |
| LCD /RESET | штатний апаратний power-on reset |
| LCD живлення / підсвічування | штатні кола дисплея |

**GPIO43/44** залишаються для UART0/COM-логів, **GPIO19/20** не займаються (native USB).

## KCX_BT_EMITTER v1.7

| KCX модуль | ESP32-S3 |
|---|---|
| RX (UART input) | GPIO4 / UART1 TX **через узгоджувач логічних рівнів** |
| TX (UART output) | GPIO5 / UART1 RX **через узгоджувач 5→3,3 В, якщо TX модуля 5 В** |
| MODE | GPIO9, режим **EMITTER/TX**, HIGH (рекомендовано зовнішній pull-up 10 кОм до дозволеної логічної напруги модуля) |
| LINK | GPIO10 (додатковий вхід стану; в поточній прошивці статус визначається через UART) |
| GND digital | спільна цифрова земля з ESP32-S3 |
| VCC | за маркуванням/даташитом конкретної плати KCX, часто 5 В |
| L/R/AUDIO GND | стерео **LINE OUT** магнітоли, аудіоземля згідно з модулем |

**Важливо:** одна з незалежних перевірок KCX v1.7 вказує, що UART-інтерфейс модуля розрахований на **5-вольтові логічні рівні**. Не підключайте TX модуля безпосередньо до GPIO ESP32-S3, доки не виміряно рівень; для надійності закладіть двонапрямний логічний перетворювач 3,3↔5 В (або відповідний буфер). Не плутайте цифрову GND та аналогову Audio GND: з'єднуйте тільки згідно зі схемою аудіомодуля/магнітоли, щоб уникнути земляних петель.

**Ніколи не підключайте вихід підсилювача/динаміків напряму до L/R.** Потрібен лінійний вихід магнітоли або відповідний speaker-to-line конвертер (особливо для BTL-виходів).

## Збірка (Windows 11, PowerShell 7, ESP-IDF 5.5.x)

\`\`\`powershell
git clone https://github.com/garik816/bluetoothModule.git
cd bluetoothModule
idf.py set-target esp32s3
idf.py build
idf.py -p COM12 flash monitor
\`\`\`

Замініть **COM12** фактичним портом. PlatformIO та Arduino не використовуються. Якщо ПК не бачить ESP32-S3 — перевірте порт USB Serial/JTAG та вивід UART0, що використовувався у Silvus.

### Робота меню

1. Увімкніть KCX у режимі **EMITTER** і навушники в pairing mode.
2. Після старту натисніть 5 міток Touch (якщо калібровка ще не збережена).
3. Натисніть **SCAN**: KCX почне пошук через \`AT+PAIR\`; знайдені пристрої з'являтимуться у списку.
4. Натисніть рядок потрібного пристрою, потім **CONNECT**.
5. Натисніть **DROP** для роз'єднання, **MORE** — наступна сторінка списку.

Фактичне аудіо йде **між LINE OUT магнітоли та KCX**, а не через I²S ESP32-S3.

## Поточний стан та валідація

- Початкова реалізація firmware та unit-тести парсера додані до репозиторію.
- GitHub Actions: \`protocol\` перевіряє UART-протокол C-компілятором Linux; \`esp32s3\` збирає прошивку ESP-IDF 5.5.
- **Робота на фізичному ESP32-S3 + FSA506 + KCX v1.7 ще не перевірена**; у різних партій KCX можливі відмінності прошивки та UART-відповідей.
- Відтворення, затримка, автоматичне під'єднання, рівні UART і стабільність живлення мають бути перевірені на стенді.
- Текст на TFT наразі латиницею: у драйвері Silvus використано простий 5×7 шрифт без українських літер. Консольна документація — українською; для українського UI необхідно додати шрифт із кирилицею.
